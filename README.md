# Asset Manager - Студия звукозаписи

Веб-приложение для управления студией звукозаписи: запись на услуги, бронирование, отзывы и общение с клиентами.

## Требования

- **Node.js** (версия 20 или выше)
- **PostgreSQL** (версия 14 или выше)
- **npm** (устанавливается вместе с Node.js)

## Установка и запуск

### 1. Установите Node.js

Скачайте и установите Node.js с официального сайта: https://nodejs.org/

После установки проверьте версии в терминале:
```bash
node --version
npm --version
```

### 2. Установите PostgreSQL

Скачайте и установите PostgreSQL с официального сайта: https://www.postgresql.org/download/

В процессе установки:
- Запомните пароль для пользователя `postgres`
- Оставьте порт по умолчанию `5432`

После установки создайте базу данных:
```bash
psql -U postgres
CREATE DATABASE mamdeev;
\q
```

### 3. Настройте переменные окружения

В корневой папке проекта создайте файл `.env`:

```env
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/mamdeev
SESSION_SECRET=сгенерируйте_случайную_строку_из_букв_и_цифр
```

Замените `ВАШ_ПАРОЛЬ` на пароль, указанный при установке PostgreSQL.

### 4. Установите зависимости

```bash
npm install
```

### 5. Создайте таблицы в базе данных

```bash
npm run db:push
```

### 6. Запустите проект

```bash
npm run dev
```

После запуска откройте браузер: `http://localhost:8000`

## Доступные команды

| Команда | Описание |
|---------|----------|

## API эндпоинты

- `GET /api/services` - список услуг
- `GET /api/reviews` - список отзывов
- `GET /api/specialists` - список специалистов
- `GET /api/bookings` - список бронирований
- `GET /api/messages` - список сообщений
- `POST /api/bookings` - создать бронирование
- `POST /api/messages` - отправить сообщение

## Решение возможных проблем

### Ошибка "DATABASE_URL must be set"

Убедитесь, что файл `.env` существует в корне проекта и содержит правильную строку подключения.

### Ошибка подключения к PostgreSQL

1. Проверьте, запущен ли PostgreSQL:
   - Windows: `services.msc` → найти "postgresql" → запустить
   - Mac/Linux: `sudo service postgresql start`

2. Проверьте правильность пароля в файле `.env`

### Порт 8000 уже занят

Измените порт в файле `server/index.ts`:
```typescript
const port = parseInt(process.env.PORT || "8000", 10);
```
